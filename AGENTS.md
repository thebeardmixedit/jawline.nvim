# Agent guidance

Use the [README](README.md) for setup and the
[reference](docs/reference.md) for behavior, the module map, and development checks.

- Before edits, inspect the branch and working tree. Preserve unrelated local
  changes; do not stash, reset, discard, stage, or incorporate them without
  explicit authorization.
- Stage, commit, push, open a PR, tag, release, or change repository settings
  only when explicitly authorized.
- Keep secrets, personal paths, and private project material out of public
  repository content.
- Validate affected behavior and report the checks performed and their limits.
  Follow the [development guidance](docs/reference.md#development-and-verification);
  do not treat the interactive development configuration as automated test coverage.
